# Formulario de Contacto La Salle

Aplicación web desarrollada para gestionar el envío y almacenamiento de mensajes de contacto.

## Tecnologías utilizadas

- Node.js
- Express
- PostgreSQL
- HTML
- CSS
- JavaScript
- Git
- GitHub
